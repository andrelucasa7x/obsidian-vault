# 13 Principios NEOTECH

> Base filosofica de toda decisao tecnica

---

## 1. Multi-engine, nao single
Nunca depender de 1 provedor. Gemini + DeepSeek + Claude + OpenAI.

## 2. Loops autonomos > pipelines lineares
O sistema deve se retroalimentar. Growth loop: publicar → medir → aprender → melhorar → publicar.

## 3. RLHF passivo > coleta explicita
Aprender das acoes do usuario (cliques, aprovacoes) sem pedir feedback direto.

## 4. Personas reais > IA generica
Cada output deve ter personalidade. NOCAST tem identidade propria, nao e "post generico de IA".

## 5. Templates como dado, nao codigo
Templates HTML sao assets estaticos. O renderer preenche slots. Nunca modifica estrutura.

## 6. Multi-tenant desde dia 1
Cada cliente = tenant isolado. NOCAST = noticias. GoalTech = apostas. Futuro politico = comunicacao.

## 7. Free APIs first
Sempre usar tier gratuito primeiro. Gemini free > DeepSeek pago > OpenAI pago.

## 8. Fallback chains
Toda engine tem fallback. Gemini falha → DeepSeek assume. DeepSeek falha → None. Nunca erro total.

## 9. Mirroring resolve CORS
RSS-Bridge como proxy. Evita bloqueio de CORS em chamadas client-side.

## 10. Catalogo pra IA escolher
Orion Router = catalogo. IA busca a skill/agent certo em vez de carregar tudo na memoria.

## 11. Departamentos > monolitos
7 departamentos de agents. Cada um com responsabilidade clara. Nao 1 agent que faz tudo.

## 12. Inovacao automatizada (T=0.9)
Temperature alta pra criatividade. Agents de P&D experimentam. Os bons ficam.

## 13. Anti-cold-start brutal
Nunca comeca do zero. 489 fontes RSS, 425 skills, 174 agents, templates prontos. Tudo pre-carregado.
